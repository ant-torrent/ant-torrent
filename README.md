# AntTorrent

[English](./README.md) | 简体中文

**AntTorrent** 是一个自托管的 qBittorrent 统一管理界面 —— 在一处管理多台远程服务器，实时掌握传输动态，用 RSS 规则自动化下载，并通过内置 AI 助手完成日常操作。

开箱即支持 qBittorrent 4.x 与 5.x，版本差异自动适配。

## ✨ 功能特性

### 🖥️ 多服务器管理

- 接入任意数量的 qBittorrent WebUI，每个页面都有服务器标签页，随时一键切换
- 保存前可测试连接，之后随时编辑；每台服务器的连接状态一目了然
- 全部数据都在你自己的部署里——你和盒子之间没有任何云端中转

### 📊 实时看板

- 实时上传/下载速度曲线，滚动历史一目了然
- 种子状态分布（下载中、做种、暂停、异常……）尽收眼底
- 本次会话与累计流量统计、DHT 节点数、剩余磁盘空间
- 当前活跃传输列表，什么在跑一眼便知

### 🧲 种子管理

- 虚拟滚动的种子列表，库再大也保持流畅
- 多条件叠加筛选——状态、分类、标签、Tracker 域名，外加名称即时搜索
- 批量操作：暂停、启动、重新校验、删除（可选同时删除已下载文件）
- 左键单击行即可选中/取消选中；右键打开覆盖所有常用操作的上下文菜单：
  - 启动、强制启动、暂停、删除
  - 设置分类与标签、移动保存位置
  - 单种子的上传/下载限速与分享率限制
  - 文件优先级与自动种子管理（TMM）
- 详情抽屉包含概览、Tracker、文件、用户四个标签页
- 列完全自定义——在 40+ 个数据字段中显示、隐藏、排序，布局自动记忆
- 通过磁力链接或 `.torrent` 文件添加种子，可提前选择保存路径（支持目录浏览）、预设分类

### ⚙️ 远程修改 qBittorrent 完整偏好设置

- 不离开 AntTorrent 即可编辑 qBittorrent 的应用设置：行为、下载、连接、速度、BitTorrent、Web UI 及高级选项
- 直接管理分类和标签，无需打开原生 WebUI
- 表单带依赖联动，各项开关始终与你所用 qB 版本实际支持的选项保持一致

### 📡 RSS 自动化

- 订阅源按文件夹组织，未读数量徽标贯穿全局
- 按发布时间浏览文章列表，一键打开原文
- 任意文章一键下载进 qBittorrent
- 自动下载规则（必须包含/不得包含关键词，随时启停），新资源发布即抓取

### 🤖 AI 助手

- 内置聊天抽屉，流式输出回复；配置好你的 LLM 接口即可使用
- 智能体工具循环让它不只是"说"——还能动手：跨服务器检索与筛选种子、查看详情、添加你提供的链接、查询分类和标签
- 助手工作过程中，每一次工具调用及其结果都清晰可见，改了什么一清二楚
- 支持 OpenAI 兼容接口与 Anthropic API
- 还可以挂载外部 MCP 工具服务器（stdio 或 HTTP）扩展能力

### 🗂️ 远程目录浏览（[ant-agent](https://github.com/ant-torrent/ant-agent)）

- 可选的轻量 Agent 部署在 qBittorrent 所在机器上，添加种子时可直接浏览它的目录来选择保存路径——AntTorrent 与 qB 分属不同主机时尤其有用（独立仓库：[ant-torrent/ant-agent](https://github.com/ant-torrent/ant-agent)）
- 仅发起出站连接：盒子上无需开放任何入站端口
- 权限天生收敛：目录白名单 + Token 鉴权，精确限定 Agent 能看到什么

### 🎨 舒适体验

- 浅色 / 深色 / 跟随系统三种主题模式，六种主题色可选
- 完整的中英双语界面，切换即时生效——连服务器报错文案都是本地化的
- 所有偏好自动持久化

## 🚀 快速开始

最快的方式是 Docker Compose：

```bash
git clone <仓库地址> ant-torrent
cd ant-torrent

# 仅 Linux 需要：容器以 uid 1000 运行
mkdir -p data && sudo chown -R 1000:1000 data

docker compose up -d    # 拉取 GHCR 预构建镜像；源码构建见 docker-compose.dev.yml
```

浏览器打开 `http://<主机IP>:8000`，进入 **设置 → 服务器**，添加第一台 qBittorrent。地址必须是**后端可达**的，例如 `http://192.168.x.x:8080`，而不是 `localhost`。

更多部署方式——源码构建、systemd 服务、常见问题排查——见[安装部署指南](docs/install.md)；在远程盒子上安装 **ant-agent** 见 [ant-agent 仓库](https://github.com/ant-torrent/ant-agent)与其[安装指南章节](docs/install.md#agentant-agent安装)。
